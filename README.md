# Інтерактивний суд ‑ дистанційний формат

Цей репозиторій містить готовий HTML‑застосунок для проведення рольової гри «Ігровий суд» у дистанційному форматі. Застосунок дозволяє вчителю створити кімнату, розподілити ролі між учнями та керувати ходом судового засідання в реальному часі за допомогою Firebase Firestore.

## Структура репозиторію

- `index.html` — основний файл застосунку. У ньому вже налаштований інтерфейс вчителя та учнів і підключено Firebase SDK. 
- `firebase.json` — приклад конфігурації для хостингу. Цей файл створює Firebase CLI під час ініціалізації; він додається тут як шаблон.

## Швидкий старт

1. **Встановіть Node.js та Firebase CLI.**  Переконайтеся, що на вашому комп’ютері встановлений Node.js (версія LTS) та NPM. Потім глобально встановіть Firebase CLI:
   ```bash
   npm install -g firebase-tools
   ```

2. **Створіть проект Firebase.**  У консолі Firebase (https://console.firebase.google.com/) натисніть *Add project*, заповніть назву і створіть новий проект. Відкрийте його після створення.

3. **Увімкніть Firestore.**  В лівому меню розділу Build виберіть *Firestore Database* → *Create database* і оберіть режим **Test mode** для початку. Цей режим дозволяє веб‑застосунку читати й записувати дані【371319024710027†L1535-L1570】.

4. **Зареєструйте веб‑застосунок.**  На сторінці огляду проекту натисніть іконку "Web" (</>) і введіть будь‑яке ім’я (наприклад, *CourtSimApp*). Після реєстрації консоля надасть об’єкт `firebaseConfig`. Скопіюйте його й замініть значення у файлі `index.html`:
   ```javascript
   const firebaseConfig = {
     apiKey: "ВАШ_API_KEY",
     authDomain: "ВАШ_AUTH_DOMAIN",
     projectId: "ВАШ_PROJECT_ID",
     storageBucket: "ВАШ_STORAGE_BUCKET",
     messagingSenderId: "ВАШ_MESSAGING_SENDER_ID",
     appId: "ВАШ_APP_ID",
     measurementId: "ВАШ_MEASUREMENT_ID"
   };
   ```
   У цьому репозиторії вже є приклад конфігурації; замініть його на свій.

5. **Ініціалізуйте хостинг.**  У корені репозиторію виконайте команду:
   ```bash
   firebase login      # вхід у Firebase CLI
   firebase init hosting
   ```
   Виберіть створений проект, укажіть директорію розгортання (поточну або `public`) та відмовтесь від створення нового `index.html`, оскільки він вже існує.

6. **Розгорніть сайт.**  Після ініціалізації виконайте:
   ```bash
   firebase deploy --only hosting
   ```
   Команда створить ваш сайт на домені `PROJECT_ID.web.app` і `PROJECT_ID.firebaseapp.com`【562956530353311†L1597-L1615】. Відкрийте отриману URL‑адресу у браузері, щоб скористатися застосунком.

## Налаштування Firestore

Якщо ви використовували тестовий режим Firestore, пам’ятайте, що він відкриває доступ до бази для всіх користувачів. Після тестування відредагуйте правила безпеки у консолі Firebase, щоб обмежити доступ, наприклад, лише для аутентифікованих користувачів.

## Файли хостингу

У репозиторії міститься файл `firebase.json`, який визначає, що весь вміст кореневої теки буде розгорнуто на хостингу. Ви можете адаптувати цей файл залежно від того, де зберігатиметься ваш `index.html`.

## Ліцензія

Цей проект надається для навчального використання. Ви можете адаптувати код під свої потреби та розширювати функціонал.
